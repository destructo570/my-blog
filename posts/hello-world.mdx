## Code

A TypeScript block with syntax highlighting:

```ts
type Post = {
  slug: string;
  title: string;
  published: boolean;
};

export function publishedPosts(posts: Post[]): Post[] {
  return posts.filter((post) => post.published);
}
```

And a shell one:

```bash
npm install
npm run dev -- -p 3005
```
